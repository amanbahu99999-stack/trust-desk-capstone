# TrustDesk Capstone Submission

## Project

TrustDesk is an AI support operations agent that provides ticket triage, policy-grounded cited replies, approval-gated refund reviews, prompt-injection blocking, audit traces, and a reproducible evaluation suite.

## Verification

Run `python3 -m unittest -v` to execute the five safety and workflow checks.
